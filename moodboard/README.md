# Moodboard — Tu Futuro Dual

Carpeta para material visual, audio y referencias de diseño.

## Estructura

```
moodboard/
├── images/       → Imágenes de referencia, fotos, ilustraciones, capturas de diseño
├── audio/        → Canciones, efectos de sonido, música de referencia
├── references/   → Links, screenshots de otras webs, PDFs de diseño
└── README.md     → Este archivo
```

## Cómo usar

1. **Imágenes**: Suelta cualquier imagen aquí — screenshots de diseños que te gusten, paletas de color, tipografías, ilustraciones, fotos de referencia.
2. **Audio**: Canciones que capturen la vibra de la plataforma, efectos de sonido para gamificación (click, level up, confetti).
3. **References**: Links a sitios web, Behance, Dribbble, o cualquier referencia visual.

## Lo que buscamos

- Dark mode con acentos neón/vibrantes
- Gamificación visual (progreso, puntos, animaciones)
- Tipografía bold y moderna
- Layouts破格 que rompan el grid
- Sensación de app/juego, no web corporativa
